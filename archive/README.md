# Archived website material

This directory preserves routes, content, components, templates, assets, and planning documents retired during the October 2026 public information-architecture simplification.

The archive is not part of the public application or content registry. TypeScript excludes this directory from active compilation.

## Provenance

- `archive/app/` contains retired Next.js route implementations originally under `app/`.
- `archive/content/` contains retired Markdown and MDX originally under `content/`.
- `archive/components/` contains unused legacy components originally under `components/`.
- `archive/lib/` contains the superseded hard-coded learning data originally at `lib/learning.ts`.
- `archive/docs/` contains the superseded site-content blueprint originally at the repository root.
- `archive/public/` contains retired public-facing asset notes and related files.

The two pharmaceutical Lab notes retain their exploratory status here and were not redirected to structured Learn lessons.
