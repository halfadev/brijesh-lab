# Homepage hand-drawn mark

The active Wacom asset is currently `public/images/complex-systems-framework.png` and is rendered by `components/HandDrawnMark.tsx`.

Place a future replacement in this folder and update that component while retaining its wrapper.

- Preferred: `home-mark.svg` with a transparent background.
- PNG: transparent, approximately 1200 × 500 px (or 2× that size for sharp rendering).
- WebM: transparent if supported by the exported codec; otherwise use a transparent-background or page-background-matched export, 3–8 seconds, muted, and looping.

Keep the composition wide rather than tall so it remains a secondary annotation beneath the homepage CTA.
