# One medicine, five systems of record

This learning pack accompanies the explainer of the same name. Add all four files to a grounded research workspace such as NotebookLM, then use the questions file to explore how evidence moves across system boundaries.

## Files

1. `01-model.md` — the five-system model and its central claim
2. `02-terminology.md` — shared identifiers and operating terms
3. `03-source-notes.md` — standards and source material behind the model
4. `04-questions.md` — prompts for analysis and discussion

## Core idea

One physical medicine can be represented by several authoritative digital records. The complete operational story emerges by assembling evidence from systems that each own a different part of reality.
