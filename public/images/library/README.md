# Image library

Reusable visual assets for the website live here. Keep filenames descriptive and stable so the same asset can be used on the homepage, in learning modules and in social previews.

## Current assets

- `pharmaceutical-lifecycle.svg` - A web-native overview of the medicine lifecycle from discovery to real-world learning. Designed for wide placements. Source viewBox: 1200 by 440.
- `pharma-complete-map/pharma-ecosystem.png` - Temporary actor-ecosystem visual for Module 1. Replace this file in place when the final version is ready.
- `pharma-complete-map/pharma-terms-map.png` - Plain-language pharmaceutical terminology map for Module 1.
- `pharma-complete-map/map-to-keep-in-your-head.png` - Closing mental-model summary for Module 1.

## Preferred formats

- SVG for diagrams, system maps and icons.
- WebP or AVIF for photographs and textured artwork.
- PNG only when transparency is required and SVG is not practical.

Keep editable source files outside this delivery folder when a visual is produced in another design tool.
