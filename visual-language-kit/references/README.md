# Reference assets

These assets show the intended visual character. Attach the smallest useful set to an image-generation request.

## `palette.svg`

Use as the color reference. The top group is the core hierarchy; the lower group contains optional category accents.

## `editorial-ecosystem-map.png`

Use as a reference for a central ecosystem, deep navy focal node, pale grouped panels, line icons, and fine connectors.

## `editorial-mental-model.png`

Use as a reference for dense but structured teaching graphics, numbered sections, process stages, and limited category colors.

## `pharmaceutical-lifecycle.svg`

Use as a reference for a clean left-to-right process, modest gradients, short labels, and phase groupings.

## `notebook-system-map.png`

Use as a reference for hand-drawn teaching sketches, ruled paper, pastel highlights, causal arrows, and a visible feedback loop.

## Reference rule

Match the visual grammar, not the subject matter. Do not copy pharmaceutical terminology into an unrelated topic. Do not reproduce a reference image element-for-element unless explicitly requested.
